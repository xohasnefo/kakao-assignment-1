# Todo 앱 (Todo App)

## 📌 프로젝트 소개
HTML, CSS, Vanilla JS만을 활용하여 제작된 깔끔하고 미니멀한 스타일의 Todo 생산성 앱입니다.  
생산성을 높여주는 메인 컬러 `#672be0`를 테마로 하여, 주간 일정을 한눈에 확인하고 할 일을 효율적으로 관리할 수 있도록 디자인되었습니다.

---

## ✨ 주요 기능

### 1. 주간 뷰(Weekly View) 캘린더 네비게이션
- 이번 주 월요일부터 일요일까지의 날짜를 가로로 나열하여 한눈에 파악 가능
- 이전 주차 및 다음 주차 이동 버튼 기능 지원
- 날짜를 클릭하면 해당 날짜에 등록된 Todo 목록만 동적 필터링
- 각 날짜 하단에 해당 일자의 총 Todo 개수를 배지로 실시간 표시
- **오늘 날짜**는 메인 컬러 배경을 적용하여 시각적으로 확실하게 구별

### 2. Todo 비즈니스 로직
- **추가/삭제**: 새로운 할 일을 추가하고 삭제 가능 (빈 값 입력 시 alert 예외 처리)
- **완료 토글**: '완료' 버튼 클릭 시 취소선 처리 및 완료 상태 전환, '취소' 시 복원
- **인라인 수정**: '수정' 버튼 클릭 시 텍스트 영역이 입력창으로 전환되며 즉각적인 내용 변경 및 저장 가능

### 3. 상태 필터 탭
- **전체 / 진행 중 / 완료** 탭 제공으로 현재 필요한 항목만 모아보기 가능

### 4. 로컬스토리지(LocalStorage) 데이터 연동
- Todo를 추가, 수정, 삭제, 완료 처리할 때마다 브라우저의 로컬스토리지에 실시간 자동 저장 (`JSON.stringify`)
- 페이지를 새로고침하거나 브라우저를 재시작해도 로컬스토리지에서 데이터를 읽어와 목록을 완벽하게 복원 (`JSON.parse`)

### 5. UI/UX 및 예외 흐름 보완
- 특정 날짜나 필터 탭에 데이터가 없을 경우, "등록된 할 일이 없습니다" 등 상태에 맞는 **빈 상태(Empty State) 피드백 메시지** 제공
- 수정 모드 등에서 발생할 수 있는 잠재적 참조 오류(Null/Undefined)를 방지하는 Guard Clause 코드를 적용하여 크롬 콘솔 에러 0개 달성

---

## 🛠 기술 스택
- **Frontend**: HTML5, CSS3, Vanilla JavaScript (오직 순수 JS로만 구현, 라이브러리/프레임워크 미사용)
- **Design Theme**: Minimal & Productive (Main Color: `#672be0`)
